## 🔍 About opencode-benchmark-dashboard

The opencode-benchmark-dashboard is a tool that helps you test how well large language models (LLMs) work with opencode. It measures two key things:

- **Speed (Latency):** How fast the model answers.
- **Correctness (Accuracy):** How right the answers are.

You don’t need any programming skills to use this app. The dashboard shows results clearly, so you can decide which model fits your needs.

## 🎛️ How to Use the Dashboard

After starting the app, you’ll see a clean interface with charts and tables. Here is a simple guide:

1. **Select Models to Test**  
   Use the checkboxes to pick which language models you want to compare. The dashboard can handle many models, including local ones.  
   
2. **Start Benchmarking**  
   Click the "Run Test" button. The system will send questions to the models and record the answers. This may take a few minutes depending on how many models you choose.

3. **View Results**  
   Once tests finish, you see results displayed by speed and accuracy. Graphs show which model responded fastest and which gave the best answers.

4. **Save or Export Results**  
   You can save the test results to your computer for future reference or share with others.

## 💡 Common Questions

**Q: Do I need internet after installing?**  
A: The dashboard runs offline for local models. You need internet to download updates or test models that run in the cloud.

**Q: Can I test any language model?**  
A: The dashboard supports common opencode-compatible models. For others, check compatibility on the GitHub page.

**Q: Is this safe to use?**  
A: The software runs locally on your PC. It does not send your data anywhere unless you use online models.
